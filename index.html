Lego Bricks Analysis

Data Visualization

A fun and colorful data visualization project analyzing the distribution of Lego bricks by color. This script demonstrates fundamental R concepts including data structures, vector operations, and creating professional-quality pie charts with custom styling.

📌 Key Features:

  • Vector creation and manipulation
  • Percentage calculations and rounding
  • Dynamic label generation with paste()
  • Publication-quality pie charts
  • Brand-accurate color representation
  • Custom borders and styling

📈 Sample Output:

The script generates a beautiful pie chart showing the usage percentages of each brick color:

🔴 Red bricks: ~28.6% (120 bricks)
🔵 Blue bricks: ~21.4% (90 bricks)
🟡 Yellow bricks: ~35.7% (150 bricks)
🟢 Green bricks: ~10.7% (45 bricks)

# Load and visualize Lego brick data lego_colors <- c("Red bricks", "Blue Bricks", "Yellow Bricks", "Green Bricks")
brick_counts <- c(120, 90, 150, 45)
visual_colors <- c("#C91A09", "#0055A5", "#F2CD37", "#237841")

🚀 Getting Started

Set up and run the R-Test Playground in just a few simple steps

1

Clone Repository

Clone the project to your local machine using Git. This brings all the code and files to your computer.

2

Install R

Ensure you have R (3.5.0 or higher) installed. We recommend using RStudio IDE for the best development experience.

3

Run Scripts

Navigate to the main.R file and execute it in your R console or RStudio to see the Lego visualization in action.

4

Customize

Modify the data, colors, and styling to experiment. Change values and immediately see how it affects the visualization.
